# 💫 Обо мне:
Начинающий Data Sciencist / ML/AI инженер с практическим опытом в классическом ML, рекомендательных системах, RAG, компьютерном зрении и деплое моделей. Сильные стороны - обработка данных (Pandas/NumPy), градиентный бустинг (CatBoost/XGBoost), PyTorch, оптимизация (Optuna), контейнеризация (Docker) и логирование экспериментов (MLflow).
